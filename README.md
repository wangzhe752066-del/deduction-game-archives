# 推理游戏档案集

个人爱好做的一些推理烧脑游戏合集，喜欢请点赞

## 在线游玩

[点击开始游戏](https://wangzhe752066-del.github.io/deduction-game-archives/)

网站通过 GitHub Pages 的 `gh-pages` 分支发布。更新源代码后，需要重新构建并将 `dist` 内容发布到该分支，网页才会更新。

中文网页推理小游戏合集。五份档案,每案 10~15 分钟可通关:你是夜班里的当事人,在监控、系统记录、平面图和手机消息之间比对细节,自己把真相推出来。

技术栈:React + TypeScript + Vite。无后端、无登录、无数据库;进度按案件分别保存在浏览器 localStorage。

## 启动

macOS 用户可直接双击目录里的 `启动游戏.command`，启动后会自动打开浏览器。游戏期间请保留终端窗口；关闭窗口后本地服务也会停止，下次重新双击启动即可。不要直接双击 `index.html`，它需要通过本地服务加载。

```bash
npm install
npm run dev        # 打开 http://localhost:5173
```

构建生产版本:

```bash
npm run build && npm run preview
```

## 玩法说明

- 打开游戏进入**案件选择页《夜班档案》**,各案进度独立(未开始 / 调查中 / 已通关)。
- 每案四个调查界面自由切换(各案名称不同:影像监控 / 系统记录 / 场景平面图 / 消息),加一块**线索板**。
- 每案 10~13 条线索,其中 5 条为关键线索;集齐 6~7 条(见各案设定)即可开始**三问推理**,答错给提示、不揭晓答案。
- 每案三个结局;真相只出现在答对后的确认语与结局文案里,列表标题与普通描述不剧透。
- 顶栏「◂ 档案」随时返回案件选择;「重新开始」两步确认后清空**当前案件**存档;通关后可返回调查补证据、尝试其他结局。
- 刷新页面会回到正在调查的案件;适配手机(底部导航)与电脑(侧边导航)。

## 目录结构

```
src/
  types.ts                # 全部数据结构(CaseData 接口:场景/平面图/记录/消息/问题/结局)
  storage.ts              # 按案件独立存档(localStorage)+ 旧版单案存档迁移
  data/cases/             # 每案一个数据文件
    case01.ts             # 档案 01 凌晨两点的最后一单(原案)
    caseDoorbell.ts       # 档案 02 只响了一次的门铃
    casePrinter.ts        # 档案 03 午夜打印的辞职信
    caseIntercom.ts       # 档案 04 来自错误楼层的呼叫
    caseGallery.ts        # 档案 05 午夜才消失的画
    index.ts              # 案件注册表(新增案件在此追加)
  hooks/useGameState.ts   # 单案状态机 + 自动存档
  components/             # 档案页/序幕/调查四界面/线索板/推理/结局等共用组件
  styles.css              # 全局样式(监控 CSS 插画、各案平面图、响应式)
```

## 扩展新案件

1. 在 `src/data/cases/` 新建一个文件,按 `CaseData` 接口写全数据(序幕、线索、监控片段含场景描述、系统记录、消息会话、平面图元素与热点、三问、结局)。
2. 在 `data/cases/index.ts` 的 `allCases` 中追加。
3. 界面、存档、推理与结局系统全部自动复用,无需改组件。

写作约定:真相只写进推理确认语与结局;片段标题与描述保持中性;关键线索必须能由玩家在界面中亲自发现(含需要「逐帧放大」才能看到的细节)。
